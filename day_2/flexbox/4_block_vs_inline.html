Dasar Elemen: Block vs Inline

Sebelum menggunakan Flexbox, ketahui perbedaan sifat dasar antara elemen Block (mengambil lebar penuh baris) dan Inline (mengikuti alur teks di dalam baris).

Contoh Perilaku:

<div>Blok 1</div>
<div>Blok 2</div>

Teks dengan link dan tebal mengalir di dalam baris.

/* Catatan dari Slide */ /* block : div, p, h1, section, form inline: a, span, strong, img, label */ /* HTML: */ <div>Blok 1</div> <div>Blok 2</div> <p>Teks dengan <a href="#">link</a> dan <strong>tebal</strong> mengalir di dalam baris.</p>
