Elemen Block vs Inline

Sebelum menggunakan Flexbox, pahami perilaku alami dari elemen block dan inline:

Contoh Tampilan:

<div> Blok 1 </div>
<div> Blok 2 </div>

Teks dengan link dan tebal mengalir di dalam baris.

Kode & Klasifikasi:

<div>Blok 1</div> <div>Blok 2</div> <p>Teks dengan <a href="#">link</a> dan <strong>tebal</strong> mengalir di dalam baris.</p> /* block : div, p, h1, section, form inline: a, span, strong, img, label */
→ Buka file mandiri: 4_block_vs_inline.html
